# App for renting cars

## Stack

- Node.js v24.15.0
- TypeScript 6
- React 19

## Scripts

- `npm run dev` - start app in dev mode,
- `npm run build` - build app
- `npm run lint` - linter
- `npm run preview` - start app in preview mode
- `npm run prettier` - format code
- `npm run stylelint` - linter for css
